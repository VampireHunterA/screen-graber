## 1. Назначение приложения

Android-приложение для Xiaomi Mi 9T (Android 11 / MIUI 12): по нажатию собственной плитки в
шторке быстрых настроек пользователь выделяет прямоугольную область экрана, приложение локально
распознаёт текст (русский + английский одновременно) и копирует его в системный буфер обмена,
после чего возвращает пользователя в исходное приложение.

## 2. Согласованные требования v1

1. Запуск режима захвата через собственную плитку Quick Settings.
2. После запуска экран слегка затемняется, появляется надпись «Выделите область».
3. Пользователь протягивает прямоугольную рамку от угла к противоположному углу.
4. После отпускания пальца рамку можно корректировать за края и углы.
5. После подтверждения выделения приложение получает изображение области и распознаёт текст.
6. OCR полностью локальный: скриншоты и текст не отправляются в сеть.
7. Русский и английский распознаются одновременно, включая смешанные строки (один проход).
8. После выделения показывается крупная кнопка «Копировать».
9. По нажатию текст попадает в системный буфер, режим захвата закрывается, пользователь
   возвращается к тому же экрану исходного приложения.
10. При отсутствии текста, ошибке распознавания или отмене приложение корректно завершает режим
    без зависания и без остаточного затемнения/overlay.

### Ограничения v1

- Только копирование текста. Без перевода, поиска по изображению, истории, облачных API.
- Без декоративных анимаций по периметру экрана.
- Без масштабного рефакторинга (проект создаётся с нуля, рефакторить нечего).
- Без изменения системных настроек и других приложений.
- Без лишних разрешений.
- Без отключения системных ограничений Android и обходных решений.
- MediaProjection не считается постоянным: согласие запрашивается на каждый сеанс.

## 12. CI-сборка GitHub Actions

Файл: `.github/workflows/build-debug.yml` — **есть в GitHub** (добавлен вручную, CI-проверен).

> История: первая попытка push из Cline была отклонена GitHub (у GitHub App нет права `workflows`).
> Workflow добавлен пользователем через веб-интерфейс; версия на GitHub отличается от исходной
> (используется `android-actions/setup-android@v4`). Локальная устаревшая копия удалена при

## 13. Установка версии 0.4.0 и проверка на телефоне

Подписи CI-сборок не совпадают между запусками, поэтому установка «поверх» завершится
`INSTALL_FAILED_UPDATE_INCOMPATIBLE`. Решение (вариант A): один раз удалить старую версию
(**это удалит локальные данные приложения — предупредите пользователя**).

```bash
adb uninstall com.screengraber.text
adb install app-debug.apk
```

**Что проверить на Xiaomi Mi 9T (Android 11 / MIUI 12):**

1. Запустить приложение один раз (пакет не должен оставаться в состоянии stopped).
2. Плитка **Screen Graber** на месте, иконка не изменилась.
3. Тап по плитке → системный диалог MediaProjection → «Начать сейчас».
4. Кадр отображается целиком с сохранением пропорций, сверху надпись «Выделите область»,
   вне будущего выделения — затемнение. Кнопки «Скопировать» нет.
5. Протяжка слева направо: рамка следует за пальцем, внутри неё изображение не затемнено.
6. Протяжка справа налево, сверху вниз и снизу вверх — рамка корректна во всех направлениях.
7. Рамка не выходит за края изображения; слишком маленькая протяжка не показывает кнопку.
8. После валидного выделения появляется компактная кнопка «Скопировать» с иконкой.
9. Нажатие кнопки → Toast «Распознавание будет добавлено следующим этапом», экран остаётся
   открытым, в буфер обмена ничего не попадает.
10. Повторная протяжка в другом месте заменяет старое выделение; кнопка снова доступна.
11. Нажатие на кнопку не начинает новое выделение (кнопка перехватывает касание).
12. Системная кнопка/жест «Назад» закрывает режим и возвращает в предыдущее приложение.
13. 5 повторных запусков: нет зависших окон, уведомлений и сервиса
    (`adb shell dumpsys activity services com.screengraber.text`).
14. `adb logcat -s AndroidRuntime:E` — без исключений.

Если плитка серая или исчезла — перезагрузка и повторное добавление: известная особенность MIUI 12.
