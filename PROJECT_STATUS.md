## 1. Назначение приложения

Android-приложение для Xiaomi Mi 9T (Android 11 / MIUI 12): по нажатию собственной плитки в
шторке быстрых настроек пользователь выделяет прямоугольную область экрана, приложение локально
распознаёт текст (русский + английский одновременно) и копирует его в системный буфер обмена,
после чего возвращает пользователя в исходное приложение.

## 2. Согласованные требования v1

1. Запуск режима захвата через собственную плитку Quick Settings.
2. После запуска экран слегка затемняется, появляется надпись «Выделите область».
3. Пользователь протягивает прямоугольную рамку от угла к противоположному углу.
4. После отпускания пальца рамку можно корректировать за края и углы.
5. После подтверждения выделения приложение получает изображение области и распознаёт текст.
6. OCR полностью локальный: скриншоты и текст не отправляются в сеть.
7. Русский и английский распознаются одновременно, включая смешанные строки (один проход).
8. После выделения показывается крупная кнопка «Копировать».
9. По нажатию текст попадает в системный буфер, режим захвата закрывается, пользователь
   возвращается к тому же экрану исходного приложения.
10. При отсутствии текста, ошибке распознавания или отмене приложение корректно завершает режим
    без зависания и без остаточного затемнения/overlay.

### Ограничения v1

- Только копирование текста. Без перевода, поиска по изображению, истории, облачных API.
- Без декоративных анимаций по периметру экрана.
- Без масштабного рефакторинга (проект создаётся с нуля, рефакторить нечего).
- Без изменения системных настроек и других приложений.
- Без лишних разрешений.
- Без отключения системных ограничений Android и обходных решений.
- MediaProjection не считается постоянным: согласие запрашивается на каждый сеанс.
